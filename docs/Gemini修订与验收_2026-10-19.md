# Gemini 建议实施与验收记录

日期：2026-10-19。对象：共桌 Common Ground 本机单用户工作台。

## 已实施

- 建议操作移入展开卡片；拒绝后待处理列表清除选择，已拒绝或暂缓建议提供恢复待处理。摘要保留首句标点与小数。
- 引用按完整原文字符偏移映射到行，跨行引用可高亮并滚动；旧版本原文缺失时明确说明，不用新原文冒充旧版。
- 多步及并发运行将每次已知用量结算费用替换对应预留；缺用量保留预留。S0 自检、S1、S5 均有回归覆盖。
- 讨论抽屉展示思考中、停止和失败原因；区分用户/AI 消息，支持 Ctrl/Command+Enter，输入法组合期间不发送。
- 空 after 表示删除，仍要求非空且唯一的 before、当前基准和来源版本；正文替换按字面处理 $& 等符号。
- DOCX/Markdown 下载使用 RFC 5987 中文文件名，附录状态中文化，时间明确为北京时间；注明处理状态截至导出时。
- 360px 检查菜单贴检查栏下方，宽度随视口约束；设置关闭通过可见确认保护未保存修改；抽屉仅在按下与点击均在遮罩时关闭。
- CMD 启停脚本统一 CRLF。
- 增加纸面轻阴影、标题分隔、段落来源标签、共同前后缀差异高亮、正文建议入口、外置角色连接选择及状态标签。Markdown 标题导入、段落标题编辑、新增/合并均保存为新版本。
- 额外修复旧建议失效后被后续无关保存或版本恢复重新激活的问题。目标段落内容/标题、约束、来源版本改变后旧建议不能自动复活。

## 对建议的核实与调整

- 未采用“UTF-8 字节数除以二就是 Token 上限”：任意兼容接口的分词器未知，不能保证该数是上限。保留保守字节预留，因此某些中文输入仍可能被高估；完成调用后按供应商返回用量和配置单价释放差额。金额上限不是供应商账单硬限额。
- 实现契约实际写的是“格式字号补丁尚未支持”，这里指格式/字号能力，没有 Gemini 所述乱码；原文保留。
- 差异采用最长共同前缀/后缀，多个分散改动之间的文本可能一起高亮；不是完整的词级 diff。

- npm run build：通过（Next.js 16.4.2，含 TypeScript 检查）。
- npm test：39 项通过。
- npm run test:http：23 项通过。DOCX 导出重新提取、中文下载头、Markdown 标题导入、新增合并和版本冲突均有隔离检查。
- 浏览器隔离验收：拒绝/恢复、纯删除生成 v2、全文跨行双标记滚入可视区、从抽屉拖拽出界不关闭、正文到建议定位、讨论快捷发送/加载态/停止入口/模拟 HTTP 401 原因展示；未保存连接关闭后编辑值保留。
- 响应式：360px 菜单位于检查栏下方（x=14、宽332），页面未出现横向内容溢出；900px 保留项目入口和方案/建议页签；1440px 桌面双栏。
- 浏览器控制台未捕获错误/警告。此前阶段截图已在目录清理时移至回收站；当前截图与验收范围见 [当前验证记录](验证记录.md)。
