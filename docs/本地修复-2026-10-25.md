# 后续本地修复与 v4 分享包

日期：2026-10-25。本说明对应当天后续修复，覆盖早期交接中“未接入/未测试”的状态。v4 是这批修复的干净源码包，仅更新本地分享文件；没有随包更新 GitHub，也没有部署或重启正在使用的服务。

## 主要修复

- 草稿暂存失败保留编辑和文本；旧基线草稿经明确确认后可另存新版本，并继续检查并发冲突、保留历史。
- 顺序部分成功保留已有分项结论；S1 比较失败只保留候选，不生成共同结论。旧建议仅在同范围同标准且本轮确有结论时替代，UI/Markdown/DOCX 标记部分完成。
- 输出结构、范围或大小校验失败时尽量保存已获得的用量、费用、请求 ID 及最多 4096 UTF-8 字节的脱敏诊断；无效输出不能应用，未知计费信息不编造。
- run 共享基础输入清单，步骤记录引用、前序 ID 与最终 hash；审计界面兼容旧记录。空事务不写盘，空编辑不改变更新时间。
- 摘要去掉正文、材料历史、消息和审计大字段；选中项目单独获取完整详情，未取得匹配详情前禁用依赖完整输入的操作。历史导出仍按真实当前版本计算待复核。
- 存储损坏明确返回 503，保留原文件和服务身份；有效变更前限频复制检查点。恢复方式见[数据恢复](数据恢复.md)，不自动覆盖损坏文件。
- 有界流读取避免 tiny chunks 数组放大；Chat 接受合规 text parts 数组。CLI 检查敏感父目录、realpath 和 Windows ADS，MCP 写操作标注同步修正。
- 并发闸按 FIFO 授予，取消和释放保持幂等。Windows/Linux 新启动记录尝试核对进程创建身份，避免只凭 PID 误认进程。
- 主页面与协作页面串行轮询、可取消、隐藏时暂停；请求键在刷新后可复用；下载先检查 HTTP 错误，延迟释放对象 URL。补齐抽屉与保存焦点、窄屏 tab/panel、版本单选键盘操作等。

## 真实边界与未完成项

API 没有账户认证、默认金额上限或速率限制，不能隔离恶意同用户进程。官方命令绑定 127.0.0.1，裸跑默认监听所有地址的 next start、反向代理和端口转发不受支持；Host/Origin 不是 socket 来源认证。

单进程同步 JSON 存储仍随历史增长，检查点不是无损备份；没有 fsync 断电保证或多进程事务锁。旧启动记录、身份不可读和未实测平台继续保守处理。存储不可写时，强制刷新仍可能丢失尚未保存的文字，应先保存或复制。

保留严格越界输出拒绝与 Next 静态页所需的 unsafe-inline。没有为消除报告条目而删除 SDK/Next 的间接依赖。大组件拆分、CSS 皮肤整合、CI、ESLint、自动组件/axe 回归尚未完成；部分连接错误仍集中页面顶部。

## 验证范围

打包前本地源码已通过 Windows / Node.js v24.21.0 的类型、格式、生产构建、106 项单测、41 项 HTTP、8 项 Agent、19 项启动器检查。使用隔离临时数据与本机模拟供应商；浏览器另验证草稿、刷新幂等、下载失败、焦点与页签。没有真实付费调用，也未实测 Linux/macOS、屏幕阅读器、自动 axe 或断电恢复。

上述是源码修复轮次的结果。当前 ZIP 的独立解压、安装、构建和测试结果以 ZIP 旁《源码包验收说明.md》为准。包内较早的全面复核、定向审查和启动复核文档保留为历史，不代表 v4 已重复其中全部人工评测。

## 已有安装升级

先备份自己的数据目录，再使用旧版停止脚本停止旧实例；覆盖源码后重新安装依赖并构建，再启动。保留自己的 `.data`，不要分享它。这个压缩包不含个人数据、密钥、依赖或预构建产物，不能直接替代已经运行的进程。
