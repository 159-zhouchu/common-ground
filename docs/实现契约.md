# 本机初版的执行契约

更新：2026-10-25（原始契约始于 2026-10-19）。此文记录代码实际采用的范围，优先解决 V4 评审发现的计数和输入可见性歧义。长期规格仍保留在原规划目录，本项目不宣称实现全部 V4。

## 策略步骤与计数

| 策略 | 实际步骤 | 调用数 | 参与连接 |
|---|---|---|---|
| S0 回答 | 指定连接回答 | 1 | 从启用连接选择 1 个 |
| S0 自检 | 指定连接回答；同一连接读取前答与原输入后自检，返回完整最终建议 | 2 | 1 个连接，2 次调用 |
| S1 独立多视角 | A、B 同一快照并行提案；独立阶段完成后用户选定的 A 或 B 显式比较，返回差异和候选补丁 | 3 | 2 个角色，比较者复用 A 或 B，无第三名隐藏参与者 |
| S5 证据优先 | A 核对当前成果和材料；B 看到 A 的结构化结果及原输入，复核引用与修订 | 2 | 2 个连接 |

策略是运行快照，不由自由生成的主持计划重排。S1 一位失败后仍保存成功候选；比较阶段能对现有候选进行有限评审，运行状态为部分完成。两位均失败不执行比较。第二步/整理失败保留第一步或独立候选，明确部分完成；不自动重试。

每次请求最多输出 3000 tokens；单调用最多等待 90 秒，整次运行最长 180 秒。调用预算在发请求前检查。没有外部工具自动执行；只把获准材料文本传入模型。没有额外的隐藏提取或汇总调用。

## 输入模式

- **继续讨论**：目标、用户确认的约束、参考材料、保存的成果、最近 10 条获准讨论。步骤之间可传递已定义的结构化结果。
- **原材料新分支**：目标、用户确认的约束、参考材料；独立提案请求排除整份当前成果（包括用户原稿）、旧聊天、问题清单与派生摘要。S0 此模式只形成候选回答，不创建可应用到旧稿的补丁。
- **S1 的显式比较步骤**：允许读取当前保存成果和新候选，输入清单明确改为继续模式；它不能再称盲答步骤。
- **S5** 必须读取要核查的当前成果，不支持同时声明 source_only。
- 参考材料由用户选择为原材料；材料本身可能已有倾向，不宣传完全无锚定。

清单保存完整实际材料文本、成果段落、可见消息和前步输出，并记录 hash；每个真实模型请求另记录实际请求体 hash。独立阶段没有对方候选。未忠实实现 SEIMAD，S4 未启用。

## 成果、问题和来源

成果是不可变 revision 加当前指针。用户编辑、采用与恢复都创建新 revision。补丁只替换一个明确 block 中唯一出现的 before 片段；服务端检查 base revision、源材料版本、状态、目标片段，不自动合并过时建议。其余内容保留。

问题处理、引用关系和编辑决定分开记录。逐字引用检查只证明提供的原文含有该句；材料是否支持结论仍是模型评审判断，需要用户核对。正确引用、模型赞同和用户采用都不升级为事实认证。无问题是合法结果。相同基准版本、材料版本、段落及 before/after 的待处理或暂缓建议不重复增加待办，原运行输出仍保留；已存在的历史重复不删除。

来源替换增加版本，保留旧文本和引用；已有问题标为 stale。用户改约束后旧待办标 stale，运行基准之后的编辑也使返回建议过时。接受建议后仍显示变更影响，未改段落不因保持原样而宣称没有关联。

## 影响检查的真实范围

- 段落被改：确定记录该段需要复核。
- 预算/日期条件有变化：通过明确关键词提出有限候选，界面显示规则名称及覆盖有限。
- 来源版本变化：提示相关判断重审。
- 其他段落：标尚未检查，**没有全面语义依赖发现**。没有经过规则检查的段落不显示“已验证无影响”。

当前没有“规则已覆盖全部字段”的检查器，故不会产生虚假的 checked 结果。格式字号补丁尚未支持，不把 V4 C09 当作已经通过。本项目未运行 V4 九例质量评测，代码测试与合成示例不是用户效果证据。

## 持久化与运行恢复

文件存储每次读取/同步事务修改/临时文件 rename 替换 JSON，限单 Node 服务进程、本机单用户；未实现 fsync 断电持久保证、损坏文件自动恢复或历史淘汰。单任务只允许一条活动运行；切换需先停止旧调度再启动新的运行。旧调用迟到仅写入旧步骤日志，不追加到新成果或讨论。

刷新从服务端恢复；页面关闭不等于停止。服务重启将运行标记 interrupted，没有冒充可恢复 worker。未保存草稿另外暂存浏览器，保存基准与暂存时间（旧数据无时间明确显示未记录）；旧版草稿不自动改基准覆盖新稿，用户需要复制重要内容或明确放弃后重新编辑。

API 的 GET/POST 均检查本机 Host；存在 Origin 时要求协议、主机与端口一致，拒绝 Sec-Fetch-Site: cross-site。无 Origin 的本机 CLI 仍可调用，这不是账户鉴权。页面拒绝第三方 iframe 嵌入；密钥不返回前端，原始供应商错误体不透传。尚无账户、租户、多人权限、生产审计或端到端数据加密，不可公网部署。

## API 连接与运行身份（2026-10-19）

已保存连接以 connectionId 稳定标识，默认最多 10 个（包含停用配置），允许同名、同模型和同供应商的独立配置。A/B 只作为本次运行的职责。MAX_CONNECTIONS 与 MAX_CONCURRENT_REQUESTS 集中在 lib/limits.ts；全进程请求并发不超过 2，不随保存数增加。排队取消的步骤不记为已发送，失败不自动重试或更换连接。

GET /api/settings、workspace 仅返回公开配置、hasKey、configured、inUse、可匹配当前配置版本的 lastTest；没有 apiKey 字段。POST /api/connections/save 保存单连接；copy 复制非敏感配置并生成新 ID；delete 删除配置和密钥，保留全部任务历史。旧 POST /api/settings 批量接口继续兼容，后端同样限制 10。达到上限时前端禁止新增／复制，后端仍独立检查。

POST /api/runs 可传 roleAssignments={a:connectionId,b?:connectionId} 和 compareRole=a/b；旧 slot 输入仍可通过迁移别名读取。S0 使用 a（旧接口亦兼容 slot=b），自检复用；S1 a/b 并行提案，再由 compareRole 比较；S5 a 初审 b 复核。POST /api/message 接收 connectionId，只调用该接收者一次。角色均可分配同一连接，但界面提示不构成异构／独立。停用、删除或未配置的选择不静默替换；项目选择按浏览器 localStorage 项目 ID 保存，未存密钥。

启动前验证所有角色并复制完整服务端配置；执行闭包不再重读设置。运行和步骤记录 connectionId 及名称、模型、基础地址、协议、结构化设置、单价、配置更新时间的无密钥快照。编辑和停用影响后续运行；运行／测试持有连接锁，结束并释放后才允许删除，取消期间尚未结束的请求同样保护。历史展示使用快照，旧记录只有原始字段时明确缺失，不根据现在的连接推测过去模型。

POST /api/connections/test 接收表单与 confirmCall=true。仅一个请求，最多 256 输出 tokens、等待 30 秒；不传项目资料，不保存表单，不重试。测试通过需符合 ReviewSchema，不证明质量。未保存的不同配置（含密钥变化）测试不会认证当前保存版本；旧测试日志没有配置版本时也不认证当前配置。测试日志最多 50 条，不存请求体、密钥和供应商原始错误。成功用量缺失、失败／取消费用均保留未知；运行输出和请求 ID 中的本次密钥回显也予以移除。

## 旧连接迁移及恢复

读取旧 A/B 数组前先检查槽位唯一且合法，生成 legacy-a / legacy-b，不以数组顺序或名称标识。原有地址、协议、模型、密钥、结构化设置和单价原样保留；原创建与更新时间不可确定，记 null。迁移前原始字节备份至 CG_DATA_DIR/backups/connections-v1.json；默认 .data/backups，不在 public，.data 被忽略。仅首次转换写 v2 envelope；后续读取不重复迁移或增建连接。无旧文件时保留两个未配置的兼容占位，可删并新增。

恢复前停止本机服务，另存当前 connections.json；将私有备份复制回 connections.json 后重新启动，会重新迁移为相同稳定 ID。只恢复连接不会删除项目；不要把工作区回退当作连接迁移恢复。旧运行不补造当时缺失的供应商信息。备份同样含密钥，应按本机私有配置保管。

本轮使用临时数据目录和本机模拟接口实际测试 10 个连接。未调用真实付费模型，未验证更高数量、多进程并发或所有供应商。

## 深色工作台与本轮限额修订

采纳前验证单段 50,000 字符、全稿 150,000 字符，超限不追加版本或修改决定。模型单步输入清单上限 100,000 UTF-8 字节，预检失败不保存该大清单，也不发模型请求；导入容量与单次模型输入容量不同。

API 流式读取请求体，JSON 限 600,000 字节，材料上传含 multipart 开销限 6 MiB，文件本身限 5 MiB。导出含 no-store。摘要轮询使用 ETag/304，省略旧版正文和步骤清单/输出，查看版本与调用详情时按项目加载完整数据。服务端依旧同步处理完整 JSON，不能把此优化表述为已解决无界历史增长。

示例明确为零次模型调用；真实检查缺可用连接时禁用，仍可导入、编辑、导出或切换合成示例。需重查建议单列，已有处理历史保留。取消控制器按项目 ID 与运行 ID 共同隔离，跨项目复用幂等键不相互取消。

## 2026-10-25 修订契约

- `POST /api/patch` 所有人工决定都要求客户端 base 等于当前版本。过期建议可按当前版本拒绝或暂缓；被新审查替代的建议不能恢复为待处理，采纳仍受独立的原文/来源/版本校验。
- `POST /api/message` 必须带 base，运行前校验版本；问答仅在获得可用回复后成对持久化，失败或取消不留下孤立提问。
- `/api/runs` 的定向审查必须带 base。普通旧客户端仍可省略；省略 base 和显式 base 是不同请求形态，重试应保持相同形态。UUID 幂等键绑定规范化选项、所选角色 ID、范围、标准和讨论问题，同键不同参数返回 409，旧版无指纹记录复用也返回明确冲突。
- 幂等重放查询原运行，不因连接配置后来改变而生成新运行或再次计费；连接配置快照在首次运行时冻结。因此请求指纹不重新纳入可变的当前配置；希望使用新配置需新建请求键。
- 定向结论按成功运行追加顺序倒序选取；同范围同标准去重时保留最近值。没有当前范围匹配时，展示最近成功运行的结论，不从 Map 最初插入位置推测新旧。
- 上传请求体限额与文件限额独立。畸形 multipart 返回 400，过大请求体优先返回 413；文件不超过 5 MiB 只是必要条件。DOCX 累计解压限 20 MiB（含图片）、1000 条目，提取正文限 50000 字符，解析限 8 秒；最多 2 个解析 Worker，超额立即返回 `DOCX_BUSY` / 429，不积压队列。V8 堆限 64/16 MiB，不等于完整进程总内存上限。
- CSP 限同源脚本、连接和表单，禁止对象与被嵌入；仍允许生产 Next 静态页面需要的内联脚本/样式，开发时另允许调试需要的 eval / 本机 WebSocket，不宣称严格 nonce CSP。
- 新写入数据文件使用 POSIX 0600，新建目录 0700，迁移备份设 0600；不追溯更改所有既有文件或目录权限。原子替换的同步短重试最坏等待约 120ms，此取舍维持现有同步事务，不能宣传为无阻塞存储。
- CLI 限请求目录，限制真实路径和常见私密文件名，拒绝硬链接及非普通文件，用同一已核验句柄限量读取。它不是操作系统沙箱，不能完整抵御具有同机目录改写权限的攻击者或其他 Agent 工具；用户仍需显式选择允许发送的内容。

上述契约在隔离临时数据与本机模拟供应商下验证。真实模型效果、跨供应商兼容、Linux/macOS 原生权限与屏幕阅读器效果不在本轮实测范围内。

## 本轮边界补充

- JSON 写接口先验证对象形态；null、数组或标量返回 400，不写入数据。
- 模型供应商完整 HTTP 响应在 JSON 解析前限制为 1 MiB，按解压后的实际流字节统计，不依赖 Content-Length。超限取消读取并返回 `PROVIDER_RESPONSE_TOO_LARGE` / 502；不重试，费用仍未知。解析后的结构化结果继续限制 9 KB。畸形 JSON 或协议信封返回安全的 `INVALID_OUTPUT` / 502。
- 讨论同键同参数先返回历史运行，再考虑新调用的连接可用性；原连接停用/删除不会触发新调用，也不会阻断历史重放。同键不同接收连接仍返回 409。新请求对停用/删除的连接继续报错。
- 协作页每次列表/详情读取结束后才安排下一次轮询，离开页面或切换记录后旧周期不再更新状态。

修正与实测范围见 [本地源码全面复核](全面复核-2026-10-25.md)。

## 后续本地修复契约（同日，覆盖上述旧行为）

- 草稿暂存失败保留编辑状态和正文。旧基线草稿须明确确认后另存新版本，保存仍以提交时所见的当前 base 校验并发；失败不会删除草稿。浏览器无法写入时，强制刷新仍可能丢失尚未落盘的文字，应先复制或服务端保存。
- 顺序策略部分成功保留最后有效分项结论，并标记部分完成。S1 比较失败仅保留候选，不生成共同结论。旧建议仅在同范围、同标准且本轮确有有效结论时被替代。
- 模型输出校验失败尽量保留已获取的用量、费用、请求 ID 和最多 4096 UTF-8 字节的脱敏诊断；诊断可能截断，不能等同完整原始响应。未取得的计费数据仍为未知；无效输出不能成为可应用建议。越界 finding 仍严格拒绝整份结果。
- run 共享基础 inputManifests，步骤引用并记录前序步骤 ID 与最终清单 hash；审计界面重建清单，旧 manifest 记录仍可读。空事务不写盘，empty edit 不推进 updatedAt；同步 JSON 存储仍随规模增长而阻塞。
- 摘要去掉所有版本正文、材料正文与历史、消息、模型输出及清单；选中项目单独获取完整详情，未取得匹配详情前禁用依赖完整输入的操作。摘要缓存按文件指纹和公开连接计算；不承诺历史无限增长时恒定响应大小。
- 存储损坏返回 503 且保留原文件；有效变更前最多每分钟复制一次检查点。详见[数据恢复](数据恢复.md)，不自动恢复，不保证断电无损。
- 主工作台与协作页采用串行、可取消、隐藏时暂停的轮询；操作错误和轮询错误分开。同签名提交在 sessionStorage 复用请求键，存储失败时在发送前拒绝提交。
- 官方启动脚本绑定 127.0.0.1。Host/Origin 检查不是 socket 来源认证；裸跑默认监听所有地址的 next start、代理或端口转发不是支持的安全部署方式。本机 API 尚无账户认证、默认金额预算或速率上限，不能隔离恶意同用户进程。已有并发、时限和输入输出限额不等同金额上限。真实模型运行仍应显式设置预算。
