# 共桌整站统一改版

日期：2026-10-22。参考：07「瑞士红白」。范围为文稿工作台 `/`、AI 协作 `/agents`、模型连接 `/connections`，不涉及 3000 端口的其他项目。

- 全站共享顶部品牌、导航、浅暖灰背景、白色面板、红色强调、字体及控件层级；取消文稿页装饰背景和重复侧栏。
- 通过 Next Link 切换页面。浏览器实际检查两页切换前后 frame ID 和 loader ID 相同，没有整页刷新。
- 文稿切页前立即暂存草稿；返回后可继续编辑。AI 协作输入切页前暂存，失败阻止离开。连接配置未保存时确认离开。
- 保留材料、讨论、版本、调用记录、检查方式、预算、输入披露、原文差异、证据、人工采纳和导出入口。手机图标有明确可访问名称。
- 表单、材料抽屉、连接列表和空状态使用同一视觉体系；小屏调整为单列，文稿和建议通过标签切换。
