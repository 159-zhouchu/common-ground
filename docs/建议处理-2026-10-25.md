# 两份评审建议的本地修订记录

日期：2026-10-25。参考工作区根目录的 `Gemini建议.md` 与 `deepseek建议.md`，逐项判断后修改当前应用源码。这些文档是外部评审意见，不作为测试结果或执行权限的依据。

## 核心行为

- 单项复查保留已有验收清单，只勾选目标项；同 ID 的标准更新，不同 ID 的标准追加。达到 6 项时提示先整理清单，不静默丢弃其他标准。
- 双填段落 ID / 材料 ID 的模型依据，仅在原文逐字命中后规范化为一个来源。需修改项可使用同验收项修改建议中、在允许段落内唯一命中的 `before` 兜底；通过项不能靠修改建议兜底。定位成功不等于主张已被事实核验。
- 删除段落后清理无效范围 ID；全部选中段落被删除时保持局部模式，要求重新选段，不自动扩大到整篇。
- 当前范围和标准的结论优先显示，其他范围与旧标准默认折叠。分项统计分别展示通过、需修改、证据不足及待复核；示例模式不评估用户自定义标准。
