## 本轮改动

- 应用布局：侧边功能导航、项目概览、检查栏、当前文稿与修改建议双栏。概览数字来自当前项目，均有对应操作入口；960px 及以下切换“方案 / 建议”，小屏收起侧栏。
- 视觉与动效：统一深色变量、玻璃面板、柔阴影、细边框、渐变网格和颗粒；按钮反馈、焦点圈、抽屉短过渡、内容渐入；低存在感粒子与漂浮几何背景，不阻挡操作。减少动态效果偏好下关闭连续动效，隐藏页面暂停粒子绘制。
- 建议操作：结果面板为标题 / 单一滚动内容 / 固定决策栏，栏内标出所选建议。材料依据折叠；失效建议单列“需重查”，不与当前待办混算。采纳仍需服务端验证基准版本、材料版本和唯一片段。
- 无 Key 流程：保留导入、编辑和导出，禁用不可执行的真实检查，提供配置和免费合成示例入口；示例标出零次模型调用，不假冒真实分析。
- 本机安全：读写 API 的本机 Host、同协议/主机/端口 Origin 与跨站请求检查；禁止第三方 iframe 嵌入，导出不缓存。无 Origin 的本机 CLI 仍可调用，未新增账户鉴权。
- 输入与版本：流式请求体上限不依赖 Content-Length；采纳修订也执行单段与全稿长度限制；Unicode 文件名不再切断 emoji；超大模型输入在保存大清单前拒绝，原稿保留。
- 轮询：ETag/304 和摘要模式，按需读取旧版正文、调用清单和原始结果。服务端依旧同步读取完整 JSON，未解决长期无界历史增长。
- 隔离与启停：HTTP/UI 测试使用随机端口、临时数据目录和实例 ID；启动拒绝无关占用，停止检查进程命令归属，重复停止幂等。修复 Windows 中文路径的进程命令读取编码；自定义数据目录内日志、PID 和 owner 一致。取消运行按项目隔离。

## 已知边界

- 未验证真实付费 API、真实费用、模型质量或用户效果；模拟协议成功不证明所有供应商兼容。
- 文件存储仍无损坏自动恢复、fsync 断电保证、数据库或历史归档；大量历史可能降低性能，需停止服务后备份数据。
- 本轮优先闭环高风险请求、输入、隔离和主路径交互；未宣称 DeepSeek 报告每个 P2 都已修复。例如损坏 DOCX 的友好错误、既有 CRLF 材料引用标准化、细分超时原因仍可继续完善。
- 仍是本机单进程单用户工具，密钥没有应用级加密；没有多人权限、联网检索、PDF/OCR、全面语义依赖或新增 S2/S4 策略。

## 交互流畅度优化（2026-10-19 傍晚追加）

用户反馈页面显示后点击、滚动卡顿。本轮先在本机复测（Chromium 155，2560×1600 @240Hz 面板，CSS 画布 1707×1067 @1.5x，滚动/点击/输入均用 DevTools 脚本测帧间隔与长任务），再只改渲染路径，不改功能、数据格式与接口。

### 改动

- 背景（历史文件 `app/ambient.tsx`，后续改版已删除）：当时移除指针视差与 pointermove/visibilitychange 监听，鼠标移动不再改写全屏背景的 transform；静态粒子等仅描述当时版本。
- 交互表面（[product.css](../app/product.css)、[workbench.css](../app/workbench.css)、[theme.css](../app/theme.css)）：菜单与抽屉去掉 `backdrop-filter` 模糊，缩小超大投影，取消 `box-shadow` 过渡，抽屉入场改为 20px 位移 + 淡入；指标卡装饰光斑由滤镜模糊改为径向渐变；文档段落不再滚动渐入（欢迎页与概览卡保留）。
- 编辑草稿（[simple-workbench.tsx](../app/simple-workbench.tsx)）：本机暂存由“每次按键同步写 localStorage”改为停止输入 400ms 后写入一次，切换项目或结束编辑时立即落盘；`dirty` 改用 useMemo；三处 ResizeObserver 增加 0.5px 死区。

### 复测结果

- 编辑模式连续输入 30 键：输入期间长任务 55/84ms → 0（5/5 次）；>20ms 帧 4 → 0；最大帧间隔 33.3ms → 中位 8.4ms（个别单帧 8.8–12.5ms）。
- 展开建议 / 打开抽屉 / 打开“更多”菜单：菜单首次点击 48ms → 16ms；抽屉最差帧 20.9ms → 16.6ms（>20ms 帧 1→0）；展开建议最差帧 29.3ms → 29.2ms（首个建议仍有一次约 30ms 首帧）。
- 滚动：文档面板、建议面板、滚轮三种场景在 1707×1067 与 1280×720 下均无 >20ms 帧，与改造前持平；本轮未复现用户实际环境中的滚动卡顿，不能保证所有设备。
- 未解决：首次进入编辑模式仍可能有一次约 60–96ms 首帧（懒编译/首帧布局，之后恢复）；指针视差移除在 CPU 计数上不可测，属合成侧减负。
- 干净复测：`npm test` 45/45、`npm run test:http` 27/27、`npm run test:launcher` 6/6、`npm run typecheck` 通过；生产构建 Build ID `NvmLdGtBH2o4TG2gLBxbA`。
- 数据：`workspace.json` 内容 SHA-256 仍为 `5C77A1964EEF373DE8D6AD3DEAA1E0837F319FB4C8668F8631B8342EC97390EA`。服务重启时应用会原子重写同内容文件，mtime 变化不代表数据变化；`.data` 内未新增/修改其他业务文件。
- 详细证据：[独立验证报告](evidence/perf-verification-2026-10-19.md)、[结构化数据](evidence/perf-verification-2026-10-19.json)、[复测截图](evidence/perf-shots-after/01-workbench.png)。

## 第二轮检查与优化（2026-10-19 晚间追加）

在上一轮基础上先做独立审计，再只按证据改动：[性能审计](evidence/perf-audit-2026-10-19.md)、[代码/CSS/包体审计](evidence/code-audit-2026-10-19.md)。

### 审计结论（摘要）

- 首次进入编辑的 58–117ms 单帧是“每个浏览器进程第一次绘制编辑器”的 GPU 光栅冷成本；4 种页内预热实测无收益，不再为它重构。
- 长文档（64 块 / 约 96k 字符）滚动本已丝滑（最大帧 4.3–4.5ms）；`content-visibility` 无帧收益且引入约 29,200px 的首次滚动高度漂移，明确不做。
- 首屏成本主要是 523KB JS 解码与 86–111ms hydration；SSR 初始数据仅省约 10ms，不做。
- 当前不需要第三轮“减模糊/减动画”；空闲轮询均为 304（约 0.6ms/s），无需改。
- 真实剩余问题集中在：首帧高度依赖 JS 测量导致布局错位；活动抽屉每次渲染都序列化所有 run/step 的 JSON；轮询响应可能乱序覆盖新状态；草稿防抖在关页时不落盘；`detailTask` 关闭抽屉后仍持有整份项目。

### 本轮改动

- 布局（[product.css](../app/product.css)）：桌面 `.cg-app` 改为 100dvh flex 列，`.cg-main{flex:1;width:100%}` 取代 JS 测量的固定高度；补充首帧高度默认值与短视口默认值；`.cg-overview/.cg-main/.cg-welcome` 显式 `width:100%` 保持原有全宽居中。示例任务先渲染 live 连接选择、再切 demo 造成的 73px 首帧跳动随之消除。
- 运行方式（[simple-workbench.tsx](../app/simple-workbench.tsx)）：用 `modeTask` 在渲染期推导 `runMode`，示例任务首帧即 demo，自有项目首帧即 live，不再闪一下连接选择。
- 交互与生命周期（[simple-workbench.tsx](../app/simple-workbench.tsx)）：三处 ResizeObserver 改为 ref 直写 CSS 变量（尺寸变化不再整页重渲染）；`load()` 增加请求序号守卫并先判 `response.ok`；挂载加载与轮询拆开；`pagehide/visibilitychange` 时立即落盘草稿；离开版本/运行抽屉清除 `detailTask`；活动抽屉的运行详情 JSON 改为展开时才序列化（JsonBlock）。

### 复测结果（本机 2560×1600@240Hz，CSS 画布 1707×1067@1.5x）

- 首帧布局：自有项目桌面 CLS 0.00001–0.00002（可视为 0）、示例任务桌面 CLS 0.0003–0.0011（改造前同一页面 0.0366–0.0751，约 50–75 倍改善）；移动端 0.007–0.0155（此前 0.046–0.103，剩余为背景轨道/导航等微位移）。首帧与稳定后的主区位置一致（示例 420.2/96.4px、自有项目 493.2/169.4px），不再有 73px 跳动；18 次导航中未再出现 demo/live 模式闪变。
- 视觉回归：1440/1280/1200/1024/960/640/390 与自有项目两种状态截图与改造前逐像素对比，最大通道差 ≤7/255，无 >12 的像素，桌面与移动端布局一致；`.cg-overview` 与主区同宽、无横向溢出，移动端页面滚动行为不变。
- 尺寸变化：离散 resize 最差帧 12.5ms、24 步连续拖拽 task 96.9ms（审计基线 20.8ms / 118ms），无 >20ms 帧。
- 交互：活动抽屉折叠时不生成 JSON，展开后 JSON 有效；草稿防抖 + 重载恢复 + pagehide 立即落盘通过；模式 demo↔live 与示例↔自有项目切换无长任务（帧最大 9.0ms）；移动 tabs 正常、无横向溢出；无 console 错误。
- 既有基线保持：滚动最大帧 5.3ms；输入 30 键最大帧 8.4ms、无 >20ms 帧与输入期长任务；帮助抽屉最差帧 12.5ms；首次进入编辑仍有一次约 87ms 冷光栅帧（浏览器进程级，一次性）。
